# Sonic the Hedgehog v1.0.0

This release carries forward the v0.8.6 gameplay and presentation fixes as v1.0.0.
The widescreen aspect dropdown now labels **32:9 (experimental)** in both the
launcher and in-game settings. Its saved value remains `32:9`, so existing
aspect-ratio choices continue to load.

The release includes aligned skipped-demo fades, continuous title-screen water,
visible escape explosions and Eggman's complete craft through the Final Zone
ending fade.
