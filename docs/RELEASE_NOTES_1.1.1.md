# Sonic the Hedgehog v1.1.1

Quick load now requires a continuous 1.5-second hold. A progress bar shows how
long to hold. Releasing early, losing focus, or opening a menu cancels the load.
Release the shortcut before using it again.

- **Keyboard:** Hold F1–F6 or F9 to load the corresponding slot. Hold Ctrl+F7 or
  Ctrl+F8 to load slots 7 and 8. Shift+F1–F9 saves on press.
- **3-button controller layout:** Hold RB to load slot 1. LB saves on press.

Widescreen now renders the title background continuously across the canvas.
Motobug previews require a valid resting pose. Crabmeat can load again when
its spawn point comes into view after an offscreen unload.

The [v1.1.0 release notes](RELEASE_NOTES_1.1.0.md) describe the optional Clone
Driver, widescreen features, and supported ROM revision. Save states are
build-specific.
