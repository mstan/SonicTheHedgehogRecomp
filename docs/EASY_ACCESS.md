# Easy level select and debug

The optional **Easy level select and debug** package appears in **Mods >
Gameplay**. Both features are disabled in a fresh profile. Enable either
feature, press Play, and restart the game after changing a running session.
The choices persist across launches and do not change sound-driver,
widescreen, controller or bug-fix settings.

- **Easy level select and sound test:** press Start on the title screen to
  open the original menu without entering a code or holding A. Use the D-pad
  to select a stage or sound, then the original menu controls to play it.
- **Easy debug mode:** press B during a normal level or Special Stage to
  enter or leave the original debug mode. A changes the selected item and C
  places it. No code or held A button is required when entering the stage.

The features are independent. Enable debug alone to retain the ordinary
title-screen Start behavior. Disable both to retain the original cheat codes.
Attract and credits demos keep their original debug behavior. The separate
**Base game bug fixes > Debug transporter escape** option remains independent.

Selections apply at process startup. Rewind, rollback and loading a state do
not apply pending menu changes. Save states and replay compatibility include
the active feature choices; sessions using different choices are incompatible.
Save states are specific to the current build.
