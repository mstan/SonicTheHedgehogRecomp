# Sonic the Hedgehog v1.0.1

- Continues Sonic's displayed run beyond the native boundary during Scrap
  Brain Act 1 and Act 2 results, allowing him to leave the wider view.
- Joins the displayed position back to the original player during Act 2's
  camera pan, preserving the scripted floor collapse and transition.
- Renders the trap floor's initial scenery before it enters the expanded
  view, using the original art until the native objects take ownership.

These changes affect widescreen presentation. The original player position,
object activation, collision and event timing remain unchanged. Visual
continuations are included in current-build snapshots and rewind state.

Fresh installations use adaptive Fit to screen; saved settings are retained.
The **32:9 (experimental)** label remains. Supply your own verified REV00 ROM.
Save states are build-specific; preserve native saves and settings when updating.
